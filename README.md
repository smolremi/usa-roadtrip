# 🏞️ USA Road Trip

A 13-day journey through 9 states and 9 national parks & monuments of the American West — built as a personal travel journal and a hands-on project to learn front-end development from scratch.

**🔗 Live site:** https://smolremi.github.io/usa-roadtrip/

## About

This site documents a real road trip from Las Vegas to Salt Lake City, covering the Grand Canyon, Antelope Canyon, Monument Valley, Mesa Verde, Black Canyon of the Gunnison, Badlands, Mount Rushmore, Devils Tower, and Yellowstone. Designed with a vintage WPA National Park poster aesthetic.

## Features

- 🌐 **Bilingual** (Polish / English) with persistent language preference
- 🗺️ **Interactive route map** (Leaflet.js + OpenStreetMap) alongside a stylized illustrated route
- 📖 **Clickable day-by-day journal** with expandable details in modal windows
- 🏔️ **Clickable park cards** with verified facts about each location
- 📸 **Photo galleries with lightbox** (previous/next navigation, keyboard support)
- ✨ Scroll-triggered animations, reading progress bar
- 📱 Fully responsive design

## Tech stack

- Vanilla HTML, CSS, and JavaScript — no frameworks, no build step
- [Leaflet.js](https://leafletjs.com/) for the interactive map
- Hosted for free on GitHub Pages

## Running locally

No build tools or dependencies required — just clone and open:

```bash
git clone https://github.com/smolremi/usa-roadtrip.git
cd usa-roadtrip
```

Then open `index.html` in your browser.
